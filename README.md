# AWS S3 Static Website Hosting

## Project Overview
A beginner cloud project demonstrating how to
host a static website using Amazon S3.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub
- Amazon S3

## Project Features
- Responsive website
- Navigation menu
- Interactive JavaScript button
- AWS S3 static website hosting

## Deployment Steps
1. Create an S3 bucket.
2. Upload website files.
3. Enable static website hosting.
4. Configure public access and bucket policy
   for this public demo website.
5. Access the website using its endpoint.
